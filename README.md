# Pruebas Libres TCAE · Práctica tipo test

Aplicaciones de práctica tipo test para los 8 módulos del CFGM Cuidados Auxiliares de Enfermería (LOGSE), Pruebas Libres de Andalucía.

Elaboradas por José Vizcaíno Blanco – SEPER La Esesita (Calañas–La Zarza). Contacto: jvizbla685@g.educaand.es

- `index.html`: portada con los 8 módulos.
- Cada módulo es un único archivo HTML autónomo (sin dependencias ni compilación) con examen real, modo examen, modo estudio, «Mis fallos» e historial.
- El progreso se guarda en el navegador de cada usuario (`localStorage`).

## Publicar con GitHub Pages

1. Sube todos los archivos de esta carpeta a la raíz del repositorio.
2. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. La web quedará en `https://<usuario>.github.io/<repositorio>/`.
